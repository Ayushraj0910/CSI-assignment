Title: Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

Abstract
Large pre-trained language models store factual knowledge implicitly in
their parameters, but this knowledge is static, hard to inspect, and hard
to update. We study Retrieval-Augmented Generation (RAG), a class of
architectures that combine a non-parametric memory (a dense vector index
over a text corpus) with a parametric generator (a sequence-to-sequence
language model). At inference time, a query encoder maps the input
question into the same embedding space as the corpus, a maximum inner
product search retrieves the top-k most relevant passages, and the
generator conditions on both the retrieved passages and the original
query to produce the final answer.

1. Introduction
Purely parametric language models struggle on knowledge-intensive tasks
such as open-domain question answering because the model must memorize
long-tail facts during pre-training. RAG addresses this by separating
"what the model knows how to do" (reasoning, language generation) from
"what the model needs to know" (facts), storing the latter in an external,
updatable index. This also improves interpretability, since the retrieved
passages act as evidence for the generated answer.

2. Method
2.1 Chunking. Documents are split into overlapping passages of a few
hundred tokens. Overlap preserves context that would otherwise be lost at
passage boundaries.

2.2 Embedding. Each passage is encoded into a dense vector using a
bi-encoder trained with a contrastive objective, so that semantically
related question-passage pairs have high cosine similarity.

2.3 Retrieval. At query time the same encoder embeds the question, and
approximate nearest neighbor search (e.g. FAISS) returns the top-k
passages by inner product.

2.4 Hybrid retrieval. Pure dense retrieval can under-perform on queries
containing rare tokens, numbers, or exact identifiers. Combining dense
similarity with a sparse lexical score such as BM25 (a hybrid retriever)
consistently improves recall on such queries.

2.5 Re-ranking. A cross-encoder that jointly attends over the
query and each candidate passage is used to re-score and re-order the
top candidates returned by the first-stage retriever, since cross-encoders
are more accurate but too slow to run over the full corpus.

3. Experiments
On open-domain QA benchmarks, RAG-based systems substantially reduce
hallucination rates compared to closed-book generation, and allow the
knowledge base to be updated by simply re-indexing new documents, without
retraining the generator.

4. Conclusion
Retrieval-Augmented Generation provides a practical recipe for grounding
language model outputs in verifiable source text, which is essential for
enterprise, legal, medical, and other high-stakes question answering
applications.
